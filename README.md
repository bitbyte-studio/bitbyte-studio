# Bit & Byte Studio

Sitio corporativo de **Bit & Byte Studio** — estudio de desarrollo web, automatizaciones, e-commerce y hardware con sede en Cuba.

## 🚀 Stack

- **Astro 7** + TypeScript
- **Tailwind CSS 4**
- **Three.js** para logo 3D interactivo
- **Sora + Inter + JetBrains Mono** (Google Fonts)
- **Material Symbols** para iconografía

## 📋 Secciones

- 🏠 **Hero** — Logo 3D animado + "Convertimos ideas en soluciones digitales" + CTAs
- ⚡ **Servicios** — Web Dev, Automatización, E-commerce con detalle expandible
- 📁 **Portafolio** — Proyectos demo con modal de vista previa
- 🔄 **Proceso** — Timeline de 4 pasos de trabajo
- 💰 **Precios** — 3 planes (Básico, Profesional, E-commerce)
- 🧰 **Tech Stack** — Grid de tecnologías
- 📬 **Contacto** — Formulario + WhatsApp + email
- 🧮 **Cotizador** — Calculadora de presupuesto interactiva

## 🛠️ Desarrollo

```bash
# Instalar dependencias
bun install

# Modo desarrollo (http://localhost:4321)
bun dev

# Build producción
bun run build

# Preview del build
bun preview
```
